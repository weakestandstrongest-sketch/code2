# Chord Finder JI — コード名検索 × 純正律

構成音からコード名を判定し、その和音を**純正律**で響かせるには各音を平均律から何セント動かせばよいかを、チューナー感覚で表示する Web アプリです。iPhone の Safari で動作し、ホーム画面に追加すればオフラインでもアプリのように使えます。

例：`ドミソ` → **C**

| 音 | 度数 | 純正比 | 平均律とのずれ |
|----|------|--------|----------------|
| C  | R    | 1/1    | 0.0 ¢          |
| E  | 3    | 5/4    | −13.7 ¢        |
| G  | 5    | 3/2    | +2.0 ¢         |

周波数比 4 : 5 : 6

## 機能

- **コード名判定**：カタカナ・ひらがな（ドレミ / れふぁ#ら）、英字（AbCEb、C3 E4 G4）、鍵盤タップで入力。候補をスコア順に表示（分数コード・テンション・omit にも対応）。
- **純正律チューナー**：各構成音の度数・純正比・セント偏差・周波数（A4 は 400〜480 Hz で変更可）をメーター付きで表示。
- **音律の切り替え**：純正律 5リミット / 7リミット（倍音列、属七の7度 = 7/4）/ ピタゴラス音律。
- **純正比の個別変更**：比をタップすると、例えば短7度を 9/5・16/9・7/4 から選び直せます。
- **0セントの基準**：コードのルート / 最低音 / 調の主音（調基準ではハ長調の Am のルートが −15.6¢ になるなど、シントニック・コンマの影響を観察できます）。
- **聴き比べ**：平均律と純正律の和音を Web Audio で再生・交互再生。
- **一括判定**：1行1コードで進行全体を判定し、各音のずれを一覧表示。
- `#q=ドミソ` のような URL で入力内容を共有できます。

## iPhone で使う

GitHub Pages で公開するのが簡単です。

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にし、このブランチ（またはマージ先のブランチ）と `/ (root)` を選んで保存
3. 表示された URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を iPhone の Safari で開く
4. 共有ボタン →「ホーム画面に追加」

ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）なので、どの静的ホスティングでも動きます。

## 開発

```sh
npm test      # エンジンの単体テスト（Node 18+）
npm start     # http://localhost:8080 で起動
```

| ファイル | 内容 |
|----------|------|
| `js/engine.js` | 入力のパース、コード判定、純正比・セント計算（DOM 非依存） |
| `js/audio.js` | Web Audio による再生 |
| `js/app.js` | 画面の描画と操作 |
| `sw.js` / `manifest.webmanifest` | オフライン対応・ホーム画面追加 |
