純正律チューナー

比をタップすると別の純正比に切り替えられます。セント値は「平均律（A4基準）からのずれ」なので、チューナーの表示をこの値に合わせてください。

※iPhoneの消音モード中は音が出ない場合があります。

音律・基準の設定は「個別」タブと共通です。行をタップすると個別表示に切り替わります。

開発目的と用途

このアプリは、与えられた構成音からコード名を判定し、さらにその和音を純正律で響かせるには各音を平均律から何セント動かせばよいかを、チューナー感覚で確認するためのツールです。

耳コピや作曲・編曲でのコード名の判定に加えて、合唱・弦楽器・管楽器のハーモニー練習や、純正律そのものの探求に使えます。

純正律の見方

純正律では、和音の各音が簡単な整数比になるように調律します。たとえば C メジャー（ドミソ）は周波数比 4:5:6 です。

  • ルート C … 0 セント
  • 長3度 E（5/4）… 平均律より −13.7 セント低く
  • 完全5度 G（3/2）… 平均律より +2.0 セント高く

マイナーコードでは短3度（6/5）が +15.6 セント高くなります。属七の和音の7度は、5リミットでは 16/9（−3.9）、倍音列に基づく7リミットでは 7/4（−31.2）です。比をタップして違いを聴き比べてみてください。

0セントの基準

  • コードのルート … ルートを平均律のまま固定し、他の音をルートに合わせます。
  • 最低音 … ベースの音を固定します。転回形・分数コードで便利です。
  • 調の主音 … 調の主音を固定し、ルート自体も主音に対して純正にとります。たとえばハ長調で Am を鳴らすと、ルートの A は 5/3 で −15.6 セントになります。コード進行によってシントニック・コンマ（約21.5セント）のずれが現れる様子が観察できます。

入力のしかた

  • カタカナ・ひらがな：ドレミファソラシ（♯ / # / ♭ / b）
  • 英字：C D E F G A B（♯ / # / ♭ / b）。大文字を含むときは英字の直後の小文字 b をフラットとして扱います（例：AbCEb）。小文字だけで入力したとき、b は音名の B（シ）です（例：gbd = G B D）。
  • 英字の後ろに数字を付けるとオクターブを指定できます（C4 = 中央のド）。省略すると下から順に積み重ねます。
  • スコアは単純で一般的なコード名ほど高く（0に近く）なります。
